GRNScope network: encoding scheme draft

A discussion mock with hand-placed nodes; the layout is not real. It shows three candidate palettes, the six direction × sign edge types, and how strength controls how prominent an edge looks. Use the buttons to check each palette under colour-blind vision and in greyscale print.

1 · Palette candidates on the same mini network

Labels sit inside the circles, with no rims. Size = number of connections. Edge width = evidence, opacity = confidence. The thick, solid edges are where the eye should land.

2 · Direction × sign, all six combinations

Colour answers "activate or repress?". The tip answers "who acts on whom?". A missing tip means the methods could not tell the direction. A hollow tip means the direction is known but the sign isn't.

3 · Strength: width (evidence or method support) and opacity (confidence)

Four width steps span a 6× range, so the strongest edges stand out. Three opacity steps separate reliable, moderate and weak edges. A missing confidence value is drawn solid.
