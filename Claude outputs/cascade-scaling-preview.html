Other ways to draw the expression cascade

Real smoothed trends from your 19-gene project (2e40f8acffeb), both lineages, 40 columns each. Rows are in today's order in every version, so only the colouring and layout change.

Now · Each row scaled 0–1 inside each lineage

CellRank's default. A flat row would be stretched into a false peak, so flat rows are hatched and labelled “Not expressed”.

Option A · Each gene scaled 0–1 across both lineages together

What the tradeSeq authors recommend for comparing lineages. A gene that is off in one lineage is simply pale there, so no hatching or special label is needed, and you can see which lineage a gene belongs to.

Option B · Branches mirrored from a shared start (Monocle 2 style)

Monocle 2's branched heatmap: the start of pseudotime is in the middle, one lineage runs left and the other right. Genes scaled across both lineages as in A. It reads as one fork instead of two panels.

Option C · Real expression values, one colour scale for all genes

No rescaling at all: colour is the log-normalised expression itself. The easiest to explain, but a gene with a low overall level looks pale everywhere, so its timing is harder to see.
