Single-cell gene expression data can support the inference of candidate gene regulatory networks (GRNs), but the resulting relationships depend on algorithm choice and cell sampling. Scores from different methods have different meanings, and agreement about a gene pair does not necessarily establish its direction or regulatory sign. GRNScope is a web server that brings inference, resampling, consensus construction and inspection of individual relationships into one workflow for researchers analysing their own data.

Input data. Users upload a gene-by-cell expression matrix as a CSV or AnnData (.h5ad) file. Depending on the analysis, they may also supply pseudotime, cell-cluster labels and a reference network. An example dataset lets users try the workflow without preparing their own input. The server checks data and identifiers before applying user-selected preprocessing and gene filters.

Processing method. GRNScope runs 13 complementary GRN inference methods through a BEELINE-derived execution layer. This layer reuses prepared inputs and workers, limits output processing and allocates computing resources across jobs. Each method is repeated on bootstrap samples of cells. For automatic resampling, GRNScope compares successive cumulative edge-recovery rankings by Spearman correlation and stops after two consecutive correlations above 0.95, up to a maximum of 50 runs. Method-specific scores are converted to ranks within each target gene before predictions are combined. The consensus reports separate measures of rank evidence, bootstrap recovery, method support, and direction and sign agreement with their evidence coverage. These measures describe computational support; none is a probability that an interaction is biologically correct.

Output and utility. Users can inspect an interactive consensus network, the method-level contributions to each relationship, repeat-run and between-method comparisons, and applicable trajectory and reference-network analyses. Edge tables and visualizations can be exported. In a completed gonadal sex determination simulation comprising 19 model variables and 2,000 cells, inspection of individual relationships shows how broad method support can coexist with weak agreement on direction. This example demonstrates how to qualify a computational prediction rather than claiming a new biological discovery.

Previous publications. GRNScope has not been published previously. It builds on the published BEELINE framework (PMID: 31907445). A related NAR resource, GRNbenchmark (PMID: 35609981), evaluates networks inferred outside its server; GRNScope instead runs inference on user-uploaded expression data and exposes the components of each consensus prediction.

Keywords: single-cell RNA-seq; gene regulatory networks; consensus inference; web server.
